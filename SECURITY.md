# Security policy

## Supported versions

Security fixes are applied to the latest ReadyKit release and the default branch.
Older releases may require an upgrade.

## Reporting a vulnerability

Do not open a public issue for a suspected vulnerability. Email
hello@level09.com with:

- A description of the issue and its impact
- Reproduction steps or a proof of concept
- Affected routes, configurations, or versions
- Any suggested mitigation

You should receive an acknowledgement within seven days. Please allow time for a
fix and coordinated release before publishing details.
