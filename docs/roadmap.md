# Roadmap

This roadmap communicates direction, not delivery dates. Proposals and feedback
belong in [GitHub Discussions](https://github.com/level09/readykit/discussions).

## Current priorities

1. Keep authentication, billing, migrations, and deployment paths current.
2. Expand integration tests around tenant isolation and provider webhooks.
3. Publish small, complete recipes for common workspace-scoped features.
4. Improve first-run diagnostics and deployment smoke tests.

## Contribution-sized work

- Add a workspace-scoped CRUD recipe.
- Add provider-specific billing test fixtures.
- Add deployment verification for supported platforms.
- Improve accessibility and keyboard navigation in the application shell.
