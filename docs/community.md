# Community

ReadyKit development is public and focused on practical Flask SaaS foundations.

## Ask and share

Use [GitHub Discussions](https://github.com/level09/readykit/discussions) for:

- Questions about architecture or setup
- Showing products built with ReadyKit
- Early feature ideas
- Patterns that may become documentation recipes

Use [GitHub Issues](https://github.com/level09/readykit/issues) for reproducible
bugs and accepted, scoped work.

## Contribute

Start with the repository's
[contribution guide](https://github.com/level09/readykit/blob/master/CONTRIBUTING.md).
Issues labeled `good first issue` are intended to be self-contained entry points.

Recipes and maintenance releases follow the [roadmap](/roadmap). No fixed
publication schedule is promised.
